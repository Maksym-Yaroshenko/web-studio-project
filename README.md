# WebStudio Project

Цей репозиторій містить виконання курсового проєкту (лабораторні роботи 1–5) з розробки клієнт-серверного веб-додатка. Проєкт пройшов шлях від статичної верстки до повноцінного React-додатка з власним REST API на базі Node.js.

## Архітектура та організація коду

Проєкт побудований як монорепозиторій і розділений на дві основні частини:

- `frontend/` — клієнтська частина (React, Vite).
- `backend/` — серверна частина (Node.js, Express).

Робота з системою контролю версій Git велася за стандартом Feature Branch Workflow: для кожного нового функціоналу створювалася окрема гілка від `main`, зміни тестувалися локально, після чого інтегрувалися в `main` через механізм Pull Requests на GitHub.

## Реалізований функціонал (за етапами)

### Лабораторні роботи 1–2 (HTML / CSS)

- Зверстано кілька сторінок за наданим англомовним макетом.
- Реалізовано семантичну HTML-розмітку.
- **Додаткові бали:** \* Використано підхід **Mobile-First**. Дизайн повністю адаптивний для мобільних, планшетних та десктопних пристроїв.
  - Побудова сіток та вирівнювання елементів виконано за допомогою сучасних стандартів **Flexbox** та **CSS Grid**.
  - Додано власну додаткову секцію, яка не була передбачена початковим макетом, для повного задоволення вимог структури.

### Лабораторна робота 3 (JavaScript)

- Додано інтерактивність за допомогою Vanilla JavaScript.
- Реалізовано модальні вікна, відкриття/закриття мобільного бургер-меню.
- Налаштовано валідацію форм і обробку подій без перезавантаження сторінки.

### Лабораторна робота 4 (React та AJAX)

- Проведено повний рефакторинг проєкту: перехід з Vanilla JS на бібліотеку **React**.
- Налаштовано збирання проєкту через **Vite**.
- Стилізацію переведено на **CSS Modules**. Кожний компонент має власну папку з файлами `.jsx` та `.module.css`, що усуває конфлікти класів та забезпечує інкапсуляцію стилів.
- Реалізовано асинхронний віджет погоди, який використовує `fetch` для отримання даних з OpenWeatherMap API.
- **Додаткові бали:**
  - Використано **Geolocation API** для автоматичного визначення місця розташування користувача.
  - Реалізовано обробку станів завантаження (loader) та перехоплення помилок.

### Лабораторна робота 5 (Бекенд та Авторизація)

- Розгорнуто локальний сервер на Node.js та Express.
- Реалізовано endpoints для реєстрації (`POST /api/auth/register`) та авторизації (`POST /api/auth/login`).
- База даних імітується за допомогою файлової системи (читання та запис у файл `users.json`).
- **Додаткові бали:**
  - Паролі користувачів не зберігаються у відкритому вигляді. Використано бібліотеку `bcryptjs` для криптографічного хешування.
  - Реалізовано безпечну авторизацію за допомогою **JSON Web Tokens (JWT)**.
  - Стан користувача зберігається у `localStorage` на стороні клієнта, що забезпечує збереження сесії після перезавантаження сторінки.
  - Реалізовано динамічний контент, що залежить від часу: створено endpoint `/api/status`, який повертає серверний час. На основі цих даних React автоматично застосовує темну тему оформлення у нічний час доби.

## Інструкція з локального запуску

Для перевірки проєкту необхідно запустити паралельно клієнтську та серверну частини. З міркувань безпеки файли `.env` не включені у репозиторій.

### 1. Запуск серверної частини (Backend)

1. Відкрийте термінал і перейдіть у директорію бекенду: `cd backend`
2. Встановіть залежності: `npm install`
3. Створіть файл `.env` у корені папки `backend` і скопіюйте туди вміст з `.env.example`:
   ```env
   PORT=5000
   JWT_SECRET=your_secret_key_here
   ```
