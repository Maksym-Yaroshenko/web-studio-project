# WebStudio Project

Цей репозиторій містить виконання курсового проєкту (лабораторні роботи 1–5) з розробки клієнт-серверного веб-додатка. Проєкт пройшов повний цикл розробки: від статичної верстки за англомовним макетом до повноцінного React-додатка з власним REST API на базі Node.js.

## Архітектура та організація роботи
Проєкт побудований як монорепозиторій і розділений на дві основні директорії:
* `frontend/` — клієнтська частина (React, Vite).
* `backend/` — серверна частина (Node.js, Express).

Робота з системою контролю версій Git велася за галузевим стандартом (Feature Branch Workflow). Для кожного нового етапу або функціоналу створювалася окрема гілка від `main`. Після локального тестування зміни інтегрувалися в головну гілку через механізм Pull Requests на GitHub, що забезпечило чисту історію комітів.

## Реалізований функціонал (за етапами)

### Лабораторні роботи 1–2 (HTML / CSS)
* Виконано семантичну HTML-розмітку на основі наданого макета.
* **Додаткові бали:** * Застосовано підхід **Mobile-First**. Дизайн є повністю адаптивним і коректно відображається на мобільних (від 320px), планшетних (768px) та десктопних (1158px) пристроях.
  * Побудова сіток та вирівнювання елементів виконано виключно за допомогою сучасних стандартів **Flexbox** та **CSS Grid**.
  * Для 100% покриття вимог до структури було розроблено та інтегровано додаткову секцію, яка не була передбачена початковим макетом.
  * Початково проєкт містив понад 1200 рядків коду в одному CSS-файлі з плавною анімацією (transition) для інтерактивних елементів.

### Лабораторна робота 3 (Vanilla JavaScript)
* Додано інтерактивність за допомогою ванільного JavaScript для маніпуляцій з DOM.
* Реалізовано логіку відкриття та закриття модальних вікон (зокрема, обробку події натискання клавіші `Escape` та кліку по бекдропу).
* Налаштовано мобільне бургер-меню.
* Виконано валідацію форм без перезавантаження сторінки з динамічним виведенням помилок.

### Лабораторна робота 4 (React, AJAX та API)
* Проведено масштабний рефакторинг: проєкт повністю переведено з Vanilla JS на бібліотеку **React**.
* Налаштовано середовище розробки через збирач **Vite** (`npm run dev`).
* Оптимізовано роботу зі стилями: масивний CSS-файл розділено на **CSS Modules**. Кожен компонент має власну папку з файлами `.jsx` та `.module.css`, що гарантує відсутність конфліктів класів.
* Реалізовано віджет погоди, який використовує `fetch` для виконання асинхронних AJAX-запитів до OpenWeatherMap API.
* **Додаткові бали:**
  * Інтегровано **Geolocation API** браузера: віджет автоматично визначає координати користувача.
  * Реалізовано відображення стану завантаження (loader) та перехоплення мережевих помилок (error handling).

### Лабораторна робота 5 (Бекенд та Авторизація)
* Розгорнуто локальний сервер на Node.js з використанням фреймворку Express.
* Використано `nodemon` для автоматичного перезапуску сервера під час розробки.
* Налаштовано middleware, зокрема `cors` для крос-доменних запитів та обробки JSON.
* Реалізовано систему реєстрації та логіну. База даних імітується читанням/записом у локальний файл `users.json`.
* **Додаткові бали:**
  * Паролі хешуються за допомогою криптографічної бібліотеки `bcryptjs`, що унеможливлює витік конфіденційних даних.
  * Налаштовано авторизацію через **JSON Web Tokens (JWT)**.
  * Реалізовано збереження токена та даних користувача у `localStorage`, що забезпечує збереження сесії при оновленні сторінки.
  * Створено ендпоінт, який повертає поточний серверний час для керування динамічним контентом (зміна темної/світлої теми на фронтенді залежно від часу доби).

## Деплой
* Фронтенд розгорнуто на платформі **Vercel** із налаштуванням змінних оточення для API-ключів.
* Бекенд розгорнуто на платформі **Render** для забезпечення безперервної обробки HTTP-запитів реєстрації та логіну.
